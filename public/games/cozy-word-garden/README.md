# Cozy Word Garden v3.7

## New pause-menu option: Exit Run

The pause menu now includes:

- Resume / Continuar
- Restart Level / Reiniciar Nivel
- Exit Run / Salir de la Partida

### Exit Run behavior
Choosing Exit Run:
- returns the player to the game's start/home screen
- resets the run to Level 1
- clears stars, coins, Golden Keys, Knowledge and streak
- clears the current board and run state
- stops and rewinds the background music
- preserves language, music and SFX preferences

Starting again creates a completely new run from Level 1.

All gameplay, bilingual educational content, secret words, rewards,
Golden Keys, responsive behavior, and the Piano & Guitar soundtrack remain intact.
